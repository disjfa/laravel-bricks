# Content API

## Versioned and read-only

The API lives under `/api/v1` with controllers in `App\Http\Controllers\Api\V1` (extending `ApiController`) and
resources in `App\Http\Resources\V1`. It only reads published content, with Sanctum tokens and their abilities
(`App\Enums\ApiAbility`). A breaking change goes into a new version, not into V1.

## Filters and sorts are shared query classes

Allowed filters, sorts and includes are defined once per model in `app/Queries` (`ModelQuery`, spatie/laravel-query-builder),
and used by both the API and the admin lists. The OpenAPI docs are generated by Scramble from the code, so keep
types and docblocks accurate.
